# Citizenship Interview Practice (pilot)

A single static page (`index.html`) for practicing the U.S. citizenship interview. No backend, no accounts, no analytics.
Practice only. Not legal advice. Not from USCIS.

Section links: `#class-practice`, `#civics`, `#have-you-ever`, `#mock-interview`.

Editable settings (host name, support link, languages, officeholder answers, speech setting) are in the `CONFIG` and `OFFICIALS` blocks inside `index.html`.
